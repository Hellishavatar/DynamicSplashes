# Dynamic Splashes

An SKSE plugin that makes jumping and falling into water react properly: ripples sized by fall
speed and stretched along your movement, splashes when you jump out of water, and the splashes the
game skips on some landings. It uses only the game's own splash, sounds and ripple simulation.
Configured through an INI.

Supports Skyrim SE and AE up to 1.7.104 with a single DLL.

Built from the Splash Ripples feature of
[Water On Steroids](https://github.com/Hellishavatar/WaterOnSteroids). With Water On Steroids
installed, turn off its Splash Ripples (`bSplashRipples = false`), so splashes don't get two sets
of ripples.
